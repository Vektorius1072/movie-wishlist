# Синеклуб — общий вишлист фильмов

Веб-сервис, где несколько человек (семья, друзья) собирают в одном месте
список фильмов и сериалов, которые хотят посмотреть: добавляют через поиск
по TMDB, голосуют оценкой 1–5, отмечают просмотренные.

## Стек

- **Next.js 16** (App Router)
- **Prisma + PostgreSQL** — рекомендуем бесплатный [Neon](https://neon.tech)
- **Tailwind CSS** — стили
- **TMDB API** — постеры, описания, жанры фильмов и сериалов
- **Resend** — отправка писем подтверждения почты
- **Upstash Redis** — rate limiting на регистрации/входе/поиске

Подробная инструкция по продакшен-деплою — в [`DEPLOY.md`](./DEPLOY.md).

## Как всё устроено

- `prisma/schema.prisma` — модель данных.
- `lib/session.ts` — httpOnly-cookie сессия (Next.js 15+ требует `await cookies()`).
- `lib/password.ts` — хеширование паролей на встроенном `crypto.scrypt`.
- `lib/mailer.ts` — письма подтверждения почты через Resend (фолбэк — печать ссылки в консоль).
- `lib/ratelimit.ts` — rate limiting на Upstash Redis (фолбэк — отключение с предупреждением).
- `lib/tmdb.ts` — поиск фильмов и сериалов TMDB (`/search/multi`).
- `app/api/auth/**` — регистрация, вход, выход, подтверждение почты.
- `app/api/groups/**`, `app/api/movies/**` — группы, приглашения, фильмы, голосование.
- `app/login`, `app/register` — вход/регистрация.
- `app/page.tsx` — дашборд (редирект на `/login`, если не авторизован).
- `app/group/[groupId]/page.tsx` — список фильмов группы.

## Запуск локально

```bash
npm install
cp .env.example .env
# впишите TMDB_API_KEY и DATABASE_URL (бесплатный Postgres на neon.tech)
# RESEND_API_KEY и UPSTASH_* можно оставить пустыми для локальной разработки

npx prisma migrate dev --name init
npm run dev
```

Откройте http://localhost:3000 — перекинет на `/register`. Если
`RESEND_API_KEY` не задан, ссылка подтверждения печатается в терминал —
скопируйте её в браузер, чтобы подтвердить почту, затем войдите.
